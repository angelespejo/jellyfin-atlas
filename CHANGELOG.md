# Changelog

All notable changes to JellyFin Atlas are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/). Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).

## [0.0.1](https://github.com/angelespejo/jellyfin-atlas/releases/tag/v0.0.1) (2026-11-11)

### Features

- **Map**: one marker per production country with current and historical borders and filming-city dots.
- **Charts**: country bars and a production-year timeline that filter the whole app.
- **Graph**: interactive network of countries and their titles.
- **Table**: sortable library with column picker and CSV, JSON and PDF export.
- **Filters**: year, type, watch state, favorites, continue watching, countries and directors, mirrored in the URL.
- **Details and panels**: title dialog, person filmography and country facts from Wikidata.
- **Interface**: English and Spanish, light/dark/system themes, keyboard shortcuts.
- **Demo mode**: bundled offline library for `pnpm dev`, no Jellyfin server required.
